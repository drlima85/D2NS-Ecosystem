## D2NS Study Hub

O **D2NS Study Hub** é a aplicação oficial da D2NS Cloud Platform.

Seu objetivo é centralizar conteúdos e materiais de estudo relacionados à Computação em Nuvem, permitindo organizar links, documentações, laboratórios, cursos e outros recursos de aprendizado em um único ambiente.

Além de ser uma ferramenta útil para estudos, a aplicação servirá como prova de conceito da infraestrutura provisionada na AWS, validando toda a arquitetura construída durante o projeto.

### Funcionalidades previstas

- Cadastro de conteúdos
- Organização por categorias
- Armazenamento de links
- Marcação de conteúdos importantes
- Listagem dos conteúdos
- Exclusão de registros

Tecnologias:

- React + Vite
- Node.js
- Express
- Sequelize
- PostgreSQL
- Docker
