# Sprint 0 — Foundation

## Objetivo

Criar a fundação do projeto **D2NS Cloud Platform**, estabelecendo a documentação, o ambiente de desenvolvimento e a estrutura inicial do repositório para suportar a evolução da plataforma.

---

## O que foi realizado

- Criação do repositório **D2NS Cloud Platform** no GitHub.
- Configuração do ambiente local de desenvolvimento.
- Instalação e configuração do Git.
- Clonagem do repositório para a máquina local.
- Configuração do Visual Studio Code como IDE principal.
- Criação da documentação inicial:
  - README.md
  - PROJECT_CHARTER.md
  - ROADMAP.md
  - LICENSE
  - .gitignore
- Definição da estrutura inicial de diretórios do projeto.
- Padronização do fluxo de desenvolvimento utilizando Git e GitHub.
- Definição da estratégia de documentação por Sprint.

---

## Decisões tomadas

- Utilizar **GitHub** como repositório oficial do projeto.
- Utilizar **Git** para controle de versão.
- Utilizar **Visual Studio Code** como ambiente principal de desenvolvimento.
- Iniciar o projeto utilizando **AWS** como primeira plataforma Cloud.
- Utilizar **Terraform** como ferramenta de Infrastructure as Code (IaC).
- Utilizar **Docker** para futura conteinerização das aplicações.
- Documentar todas as etapas do projeto por meio de Sprints.

---

## Lições aprendidas

- Uma boa documentação facilita a evolução do projeto.
- Trabalhar primeiro na arquitetura reduz retrabalho durante a implementação.
- O Git não versiona diretórios vazios, sendo necessário utilizar arquivos `.gitkeep`.
- Manter um padrão de organização desde o início torna o projeto mais profissional.
- Trabalhar localmente com Git e VS Code oferece maior controle sobre o desenvolvimento.
