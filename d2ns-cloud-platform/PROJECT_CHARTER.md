## Objetivo

Desenvolver uma plataforma Cloud moderna utilizando Amazon Web Services (AWS), aplicando boas práticas de Arquitetura Cloud, Infraestrutura como Código (IaC), DevOps e Segurança.

Como prova de conceito da infraestrutura será desenvolvida a aplicação **D2NS Study Hub**, responsável por validar toda a arquitetura implementada através de uma aplicação web real.
